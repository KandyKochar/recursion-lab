# Recursion Lab

A Java lab implementing and testing various recursive algorithms to solve classic computational problems.

## Overview
Explores recursion through practical implementations of common algorithms, demonstrating base cases, recursive calls, and problem decomposition.

## Features
- Factorial and Fibonacci implementations
- String reversal using recursion
- Binary search recursive implementation
- Recursive sum and power functions
- Stack trace analysis of recursive calls

## Technologies Used
- **Language:** Java (JDK 8+)

## Project Structure
```
src/
+-- RecursionTest.java    # Recursive algorithm implementations and tests
```

## Usage
```bash
javac src/*.java -d out/
java -cp out/ RecursionTest
```
